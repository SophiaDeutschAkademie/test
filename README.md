# 독일어 레벨 테스트 (Einstufungstest Deutsch)

소피아 독일어학원의 레벨 테스트 웹앱입니다. 학생이 화면에서 답을 누르면 결과가 자동으로 나옵니다.

- 40문항(A1–C1 레벨마다 8문항), 15분. 시간이 끝나면 자동으로 제출됩니다.
- 보기 순서는 학생마다 섞이고, 「잘 모르겠어요」를 눌러 짐작 답을 줄일 수 있습니다.
- 판정: 맞힌 문항, 틀린 문항, 모르겠다고 한 문항을 모두 문항 난이도와 함께 반영해 능력을 추정하고, 수준(입문·A1–C1)과 추천 반(문법 과정, A2·B1·B2 과정, 개인 수업)을 계산합니다.
- 결과 화면: 추천 반, 수준(하·중·상), 레벨별 정답, 더 공부할 문법.
- 선생님께 보내기: Modelltest와 같은 제출 주소로 선생님 메일에 결과가 전송됩니다. 결과 복사와 txt 저장도 할 수 있습니다.
- 풀던 내용은 기기에 자동 저장되어 새로 고침해도 이어서 풀 수 있습니다.

## 파일
